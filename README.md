## App Details

### 1) Fuellens

**Purpose:**  
Provides a practical dashboard experience based on ChronoAnalyser concepts.

**Key features:**
- Dashboard-focused view for quick insights
- Structured data presentation for easier interpretation
- Browser-based access with no local setup required

### 2) FuelCalc (Glucose/Fructose Ratio Calculator)

**Purpose:**  
Helps estimate and compare carbohydrate ratio plans for endurance fueling.

**Key features:**
- Glucose/fructose ratio calculations
- Fast scenario comparison for fueling planning
- Simple web UI for quick adjustments
